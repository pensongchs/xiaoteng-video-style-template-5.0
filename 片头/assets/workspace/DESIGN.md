# 房产片头模板｜大厂深空质感与主题抠像玻璃接力

本文件是“极限小滕”房产视频片头、开场与开头钩子的当前默认制作指令。用户当次要求优先；本模板用于学员工作目录中的片头母工程。

## 1. 风格与入口

用户确认的“临街房选楼层”片头是当前风格与质量参照。采用**大厂深空质感**（参考苹果 Keynote / 华为发布会 / 字节系深色产品页 / Linear·Stripe 级科技 UI）：深空冷色底（#07090f→#0c1220）+ 克制冷青蓝/靛紫 soft glow + 极淡网格与斜高光扫；住宅装入半透明玻璃卡片（冷灰细边+柔影，无倾斜拼贴）；强调色用电青 #7aa2ff 与去饱和冷香槟银 #c5b89a；平滑缓动，禁止土黄块与粗金条。

- 风格预览：仓库根目录预览图中的参考关键帧和手机可读性图。

- 母工程：src/Opening.tsx、src/openingConfig.ts、src/Root.tsx。
- 默认背景：「大厂深空质感背景」（深空冷底 + soft glow + 极淡网格 + 斜高光扫 + 玻璃卡片），无纸纹、无杂志相框、无阶跃错位色板、无 ASCII/粒子、无暖金 blobs。
- 字体加载与标题材质：Opening.tsx中的useFonts、Display。
- 默认规格：16:9、1920×1080、50fps、H.264、纯画面。

每期主体、位置、镜头数、换位时机和停留按文案重新设计，不机械复制参考期的房屋、人物或2.54秒时长。优先用户素材及可精准定位的现有素材；缺少合适主体时才生成。认可成片、规划、预览和其引用的正式素材作为模板参照保留，后续期使用自己的主题路径。

## 2. 背景

默认结构（Opening.tsx「深空底 / 环境光 / 网格 / 斜高光扫 / 薄色层 / 暗角 / 玻璃卡片」）：
- 深空底：linear-gradient(168deg) #07090f→#0a0e18→#0c1220→#0b101c→#09101a。
- 环境光：左上冷青蓝径向 soft glow + 右下靛紫径向 soft glow + 中央冷白提亮；随节拍轻微脉动，平滑漂移。
- 网格：约 80px 极淡产品网格，径向 mask 收边，透明度约 0.045。
- 斜高光扫：换位时一道 screen 混合的细斜扫（冷白→淡香槟银），低透明度，非粗金竖条。
- 薄色层：左侧极薄冷蓝渐变竖带 + 右下低对比靛紫柔形 + 1.5px 冷银/电青细高光线；大留白，平滑缓动。
- 暗角：克制径向暗角。
- 玻璃卡片：圆角半透明冷边框 + inset 高光 + 外柔影 + backdrop blur；水平进出，无倾斜 Polaroid。
- 身份条：右上玻璃胶囊（电青小圆点 + 冷灰字），细线边，无奶油大色块。
- 自检：无土黄 #e3a641 大块、无奶油身份底、无纸纹 SVG、无杂志倾斜相框、无约12fps阶跃错位、无暖金 blobs、无 ASCII/粒子。

以useCurrentFrame/useVideoConfig确定时间。背景运动服从主体。Opening默认背景为大厂深空质感（纯CSS光影+网格）；039 ASCII适配仍保留在components中备用，用户当期明确指定其他背景时使用对应现有适配。背景试片使用包含背景名的独立输出路径，确认后更新正式参照及当前有效说明。

## 3. 透明主体与图文换位

1. **每期按当期主题生成对应抠像**（建筑、场景或物件），不复用固定几张示意楼；用图像模型出真实比例、自然照片质感的透明 PNG，边缘干净。保持**正常自然色**（滤镜约 saturate(0.85–0.9)、contrast(1.05)、brightness(1.03–1.04)），只避免过艳抢背景。保留透明通道与必要的语义色彩差异（类别对比仍要一眼可辨）。避免白模、玩具、积木和抽象块面。随包两张住宅仅为学习示意，制作其他主题时必须按本期含义更换。
2. 独立主体必须是真实透明抠像，边缘干净，无矩形底、白边、装饰边框、折角和异常光晕；投影沿轮廓自然衰减。装入玻璃卡片时卡片本身提供边框，抠像文件仍保持透明通道。
3. 一拍一个主要焦点。中性环境可以先建立，讲到对象时突出；未讲的独立证据、数值、风险或结论保持隐藏。
4. 多个主体通过约300—500毫秒的交叠渐变与小幅位移接力，主次明确；短文案减少主体数量和切换次数。
5. 需要左右换位时，默认使用约500—650毫秒的一次连续动作，文字沿上方弧线、主体沿下方移动，避免交叉遮挡；动作建立后稳定停留。
6. 已讲信息可保留为主题锚点，降低尺度或亮度；主体没有后续用途时顺滑退出，不同时堆满画面。
7. 建筑、道路贴边时留出血并检查全程边缘；可自由移动的主体保持完整轮廓。近景在最终尺寸下必须清晰，不放大模糊素材。
8. 生成素材的视觉示意性质记录在规划中，不冒充真实楼盘、住户、现场或测量证据；涉及机制、结构或数据时按需要显示简短“示意”。普通场景和情绪抠像不增加常驻说明性页脚。

## 4. 文字节奏与阅读停留

- 默认按中文语义短语成组出现，以约120—220毫秒柔和淡入，避免机械逐字跳出、反复弹动和频繁更换短连接词。
- 已建立的主词尽量保留到当前语义段结束；短问句可以采用“主题锚点＋问题＋重点”的累积方式，避免前词刚看清就消失。
- 入场后尽量留出600毫秒以上的清楚阅读时间。实际口播较短时优先减少屏显文字和切换次数，不擅自延长视频；用户允许调整时长时再延长停留。
- 默认保持字幕和自动词元原样；动作按对应语义段起点规划。用户要求按词元精确出现时执行精确节点；同一语义短语可在所属段落开始时整体建立，不提前揭示后文独立观点或结论。
- 保留必要的否定、条件、数字和单位，不默认逐句复述口播；主词默认无逗号、句号、感叹号、问号等标点。
- 同一字区确需换组时先退出前组；本期已保留文字不要再频繁换位。重点建立后保持坐标稳定。

## 5. 字体与排版

标题使用public/fonts/JiangChengLvDongSong.ttf江城律动宋原字重；必要辅助词用AlibabaHealth-Bold.ttf真实粗体；账号ID用AlibabaHealth-Regular.ttf常规。整期视觉字体样式不超过三种，不合成粗体，不挤压或拉伸字形。

1920×1080参考：主词约200—248px，短前缀或主题锚点约110—150px，必要辅助词约80—92px，ID约26—30px。大小服从当期构图与最长文字，四周预留约100px安全区，行高参考1.12。

普通重点用冷白银渐变 #f7fbff→#e8eef8→#c5d0e0→#7a8799；判断、矛盾或语义重点用去饱和冷香槟银 #f4f0e6→#e4d7bc→#c5b89a→#8a8070，清楚但不土黄。复用Display的轻微暗色下层位移与柔阴影，冷银下层#1c2434、强调下层#2a3348，不使用厚描边或频繁扫光。

保持清楚的阅读顺序、对齐与语义间距。320×180手机尺寸检查一眼可读，原尺寸检查字形、边界、数字、单位、遮挡和透明边缘。

常驻身份条完整显示`极限小滕 房产科普`：右上玻璃胶囊（电青小圆点 + 冷灰字 rgba(180,196,220,.88)），右边距约88px、顶边距约40px，稳定完整，不参与主标题换位。

## 6. 时间码与工程

按指定文案的首尾范围制作，不额外延长。帧数为round((结束毫秒−开始毫秒)×fps/1000)，相对节点统一减去片头起点，取整误差不超过一帧。规划写明原视频起止、输出时长、帧率、帧数、剪辑放置起点及时间依据；自动词元如实注明，实际核听后才标记原声音画同步通过。

默认纯画面。用户要求使用既有音频时按同一区间接入并检查实际输出音轨。配置、组件读取、Root注册、素材路径、帧率和时长保持一致；渲染命令显式传入成片路径，静帧命令传入对应帧号与预览路径。复用跨项目共享依赖，不新建重复母工程或长期依赖目录。

每期先写规划，至少包含完整文案、时间依据、首尾范围、素材来源与性质、字体、规格，以及“时间区间／对应短语／主视觉与焦点／景别与层次变化／屏显及停留／下一拍衔接”节点表，再准备素材、修改工程、完整渲染与检查。

## 7. 归档与交付

- 规划：分镜规划/{期名}/{期名}_片头规划.md。
- 正式素材：public/assets/{期名}/。
- 预览：预览图/{期名}/。
- 正式成片：renders/{期名}_{范围}片头.mp4。

同一期维护一份当前有效规划、源码与输出，同名覆盖对应成片、预览和检查结果，不维护重复版本。原始素材、原版动效和明确保护的参照资源保留；清理按项目规则执行。

最终MP4检查分辨率、帧率、帧数、时长、完整解码、音轨和黑帧；抽取首尾、短语入场、换位中间帧和稳定落版，核对深空冷底与 soft glow 层次、斜高光扫与玻璃卡片、网格、亮部细节、主体透明边缘、层次、文字可读性、身份条、安全区及道路出血。未通过则修正受影响部分并重渲染。实际速度播放和音画同步只报告真实完成的检查，内部检查不替代用户确认。
