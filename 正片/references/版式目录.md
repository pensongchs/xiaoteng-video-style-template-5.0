# 5.0 新定版（玻璃v6 + 房产MG）· 版式目录

每种版式由 `src/style/layouts.ts` 给出「独立 MG 组」的矩形，再由 `src/style/archetypes.tsx` 填入组件。画布是 1920×1080 的 12 栏网格：左边距 96，栏宽 106，间距 24，内容右边界 1632。内容区从 y=248 到 y=880，底部 180px 留给字幕。

| 版式 | 适合的文案 | 画面结构 | 主要 MG 动作 | `data` 字段 |
|---|---|---|---|---|
| `titleFloat` | 开场钩子、本期主题 | 左 6 栏放大标题（两行，第二行金色），右 5 栏上面是媒体框、下面是提示条 | 胶囊依次弹出 → 标题上滑 → 金线划出 → 媒体框从右侧滑入 → 提示条 | `chips[] line1 line2 sub media callout icon` |
| `bareNumber` | 一个关键数字（首付、总价、预算） | 左边一个超大数字，下面跟公式和胶囊；右边是媒体框 | 数字从 0 滚动到目标值，公式里的金色字段亮起，胶囊依次出现 | `chip label value dec unit formula chips[] media` |
| `splitVs` | A 对 B（新房对二手、两种方案） | 上半是左右两个媒体框，下半是左右两组数字，中间一个箭头 | 两侧错开入场，数字同时滚动，胜出的一侧加亮 | `winner:'L'|'R'  L/R:{media label value dec unit chip}` |
| `waitVs` | 时间或等待上的对比（期房对现房） | 跟 splitVs 结构一样，但媒体框是视频，数字放大 | 两侧视频同时播放，数字滚动后出现胶囊 | 同 splitVs |
| `timeline` | 流程、步骤（3–5 步） | 横向时间轴，节点下方放说明和胶囊，底部放提示条 | 线条逐段画出，当前步骤高亮并沿轴移动（焦点按镜长自动分配） | `steps[{t s chip}] note{t}` |
| `ringFeature` | 比例、占比（贷款占比、首付比例） | 左 6 栏媒体框，右上是圆环，右下是数据卡 | 圆环从 0 画到目标比例，中心数字跟着滚动，数据卡滑入 | `media ring{ratio label value note} a{k value sep unit s}` |
| `quoteStack` | 清单类观点（几项注意事项） | 左边是引号大字观点，右边是带编号的条目，下面是警示条 | 条目依次滑入，焦点逐行下移，最后出现珊瑚色警示 | `quote sub rows[{t s k}] warn` |
| `mediaRows` | 带配图的清单 | 左边媒体框，右边是编号条目 | 同 quoteStack，但左边换成画面 | `media rows[{t s k}]` |
| `triadSoft` | 小结（三个数字放在一起） | 三栏（3/4/3 栏宽，中间一栏最重），底部提示条 | 三个数字依次滚动，中间一栏为金色 | `cols[{k value dec sep unit s}] note{t}` |
| `outroHost`（=`outroAir`） | 片尾总结 | 小滕挥手默认占左约 1/3、底边贴底；文案右 5–11 栏分层（character:false 时居中） | 小滕滑入 → 眉标 → 主句上浮 → 金线 → 要点逐条滑入 → 收尾句 → 署名；之后小滕呼吸+摆手 | `eyebrow line points? note? account? character?`；禁止点赞/关注类引导语 |

## 5.0 数据版式（组件在 `src/style/DataCharts.tsx` / `DataCharts2.tsx`，小样见 composition `DataChartSample` / `DataChartSample2`）
锚点键统一为 `draw`（说到这个词时开始画线/长柱/点亮），没填就按默认帧入场。尺寸规则：协调合理、不过小不过大，内容占矩形 55–75%，每镜一处金色。

| 版式 | 适合 | `data` 字段 |
|---|---|---|
| `lineReveal` | 逐年走势 | `pts[{x:'2019', v:1.52}] peak:拐点下标 unit vMin vMax drawDur?`（拐点亮点 + 96px 大数字） |
| `barGlow` | 3–4 项金额构成 | `bars[{k v hi?}] unit vMax barW?`（hi 只给一根，金色） |
| `rankBars` | 4–5 项排名 | `rows[{k v}]`（按从大到小，第一名自动金色） `unit vMax` |
| `waffle` | 每 100 人里… | `on:点亮格数 unit caption(可 \n) value:补充一句` |
| `balance` | 两方案总账 | `L/R:{k v s}` `tilt`：负数=左侧重（金色给重的一侧），建议 ±5–8 |
| `yearRing` | 第几年达到… | `years key1 title(可 \n) sub side[{k v}]`（30 段刻度 + 0/10/20 年份标点，区别于 ringFeature） |
| `formulaCalc` | 计算过程 | `terms[{v k}] ops[] result unit note`（result 必须按公式算过） |

## 通用字段
- `kicker`：左上角的栏目行，例如「第一笔账 · 首付」。`city` 可选填，填了就显示为「杭州 · 第一笔账 · 首付」。
- `title`：标题。titleFloat、quoteStack、outroAir 三种版式不用这一行。用 `{…}` 包住的部分显示为金色，**每个标题最多一处金色**。
- `bg`：背景。`{src, video?, blur?, dark?, trim?}`，dark 一般取 0.4–0.6，5.0 实际压暗量 = max(0.13, dark−0.26)（4.5 为 max(0.22, dark−0.16)）。
- `at`：本镜从哪句口播开始（`{cue: 句子序号}` / `{text: '句中文字'}` / `{ms}`），时长自动算到下一镜开始，不再写 `sec`。
- `anchors`：动效锚点，键见 `音画同步与字幕.md` §2，值是口播里的词。

## 新增一种版式时
1. 在 `layouts.ts` 里只用 `rect / cols / splitRows` 定义矩形，不要手写坐标。独立的组之间至少留 48px，左右相邻的组之间空出一栏。
2. 在 `archetypes.tsx` 里写 View，并注册到 `VIEWS`。
3. 运行 `npm run stills`，DOM 检查要全部显示 ✓，再逐张看定格图。

执行条款：
1. 标准8–12镜一期至少7种版式，其中至少2种不同的已定房产MG；短片少于7镜时不硬凑7种，逐镜不重复，优先安排1种语义匹配的房产MG。禁止为凑数量造数据。

4. 清单/避坑优先 pitfallBoard、layerReveal，配合 quoteStack/mediaRows；楼层用 floorLadder，预算用 paymentSplit/priceStep，配套/区域用 amenityOrbit/districtTags；评分、热度必须有来源和口径，没数据就不造分。
5. 对比/决策轮换 decisionFork、splitVs、waitVs，真实总账可用 balance；禁止默认使用 unitCompare 或旧 vsScore。
6. 背景优先清晰视频，静图背景占比≤1/3；不整屏模糊，bg.blur=0，靠冷灰玻璃和字影保证可读。
7. 卡片按口播锚点单调入场，16/20/12帧后精确停稳；禁止过冲、落地二次弹、邻居让位、整体呼吸/焦点缩放、僵硬扫光条。高亮只改变轻色光/文字亮度；数据绘制、进度填充、背景自然运镜与小滕人物摆手可保留，不让卡片整体晃动。

唯一登记：`src/style/layouts.ts` 的 DEFAULT_LAYOUTS（10+7+9）；默认活目录 `src/gallery/shots-mg-gallery.ts` / `MgGallery`，每个默认版式一镜。房产子集 `shots-mg-re10.ts` / `MgGalleryRe10` 固定9镜、40.5秒；“re10”仅兼容旧文件名，不代表10套。
检查：`npm run check:freeze` 验证材质、动效范围、默认/存档边界和gallery覆盖；正式出片还须 `npm run check`、stills/音画核验。新增版式必须先登记样镜并审核，不能直接加进默认清单。

## 共享玻璃 v6（已定参数）
- 唯一来源：`tokens.ts: GLASS_V6`；`FROST = GLASS_V6`，`GLASS.dark/light` 是同源兼容视图。所有正片玻璃入口用 `glassMat(mode,tint?,edge?,soft?)`；mgEstate.frost 与旧 mgCards.LG 均委托它。旧 light/pearl 名称保留接口，但不再渲白卡；旧 edge 参数不覆盖细白边。
- 主底：165°，rgba(62,64,72,**.68**) → rgba(38,40,48,**.74**)；基础透射约32%→26%。soft/ghost：.62→.68（基础透射38%→32%）。这是**底层不透明alpha**，不是“透明度68%”；叠加层后的有效透射会略低。
- 细白边1px，alpha .22；轻顶缘1px .26；轻底线1px黑 .12；阴影 `0 8px 20px rgba(0,0,0,.20), 0 1px 3px rgba(0,0,0,.12)`。
- 固定宽柔面光：160°，白 .12→.035（38%）→0（60%）。无移动扫光、颗粒纹理、厚斜面、双层厚框、夸张弧面或重影。
- 轻语义tint：金/暖珊瑚 .10，青绿/蓝 .08；旧接口传入更浓rgba会钳至≤.10。保持冷灰基调、暖白主字/浅副字；不改成白底或彩色实心板。
- `backdropFilter/WebkitBackdropFilter='none'`：保留经典参考的环境透射细节，用确定性半透明和面光做玻璃层次，避免祖先opacity/filter改变backdrop root而闪烁。不是28px雾化玻璃，也不是v5厚斜面版本。
- `useSpringP/useLiquid` 旧API适配有限时长ease-out cubic `1-(1-t)^3`；p严格[0,1]、到期精确1，sx/sy=1；主卡16、柔和20、小标签12帧@30fps。SPRING旧令牌改成 damping26 + overshootClamping，保留给外部兼容；本模板卡片不再用物理弹簧驱动。
- `Sheen` 兼容API返回null，`bump`返回0；关闭卡片整体前景视差、焦点推近和WordSheen。保留背景视频和有意义的数据变化；人物摆手不是卡片动画。
