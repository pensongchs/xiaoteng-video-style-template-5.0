# 音画同步与字幕

学员给你 **口播音频 + 带时间码的字幕**，成片要带声音和字幕，画面在说到哪句时切到哪个镜头，卡片和文字在对应口播刚开始时入场。

## 1. 输入：`template/episodes/<期名>/`
| 文件 | 必需 | 说明 |
|---|---|---|
| `audio.mp3 / .m4a / .wav / .aac / .flac / .ogg` | ✓ | 口播音频，只放一个 |
| `*.srt` | 二选一或都给 | 句级时间码，**决定镜头切点和字幕分句** |
| `*.json` | 二选一或都给 | Remotion Caption 格式 `[{text,startMs,endMs,timestampMs,confidence}]`，逐词或逐字。**有它才有卡拉 OK 高亮和精确的动效锚点** |

只有 JSON 时会自动分句：遇到标点、停顿超过 350ms 或超过 18 字就断句。两种都给时，SRT 定分句，JSON 定逐字时间（按字数比例对齐，文字可以略有出入）。

```bash
npm run episode -- 期名     # 解析字幕、读音频时长、拷贝音频，生成 src/demo/episode.json
```
之后 `check / stills / render` 会自动沿用这一期；episodes 里的文件有改动就自动重新准备。

### 用学员自带的「生成带时间码字幕」工具
```bash
bash 生成带时间码字幕/scripts/run.sh 音频.mp3 期名
# → 字幕文件/期名_自动时间码字幕.srt + 期名_自动动效时间轴.json，拷进 episodes/期名/
```
**语音识别出来的字一定要校对**（对照口播稿）：
- 只改文字，**不要改时间码**；
- 同音错字最常见：月工→月供、汽税→契税、七房→期房、网签备案、避坑、备好……
- 被拆开的小数要合并成一句：「大约要30」「6万」→「大约要30.6万」（时间取前一句开头、后一句结尾）；
- JSON 里对应的词也一起改（不改也能用，只是高亮的字可能对不上）。

## 2. 镜头怎么对齐音频（`src/sync/timeline.ts`）
- 帧换算：`F(ms) = ceil(ms × 30 / 1000)`。
- 每个镜头在 shots.ts 里用 `at` 指定**从哪句开始**：`at: {cue: 7}`（第 7 句）、`at: {text: '第二笔账'}`（第一次说到这几个字的那句）或 `at: {ms: 23680}`。第一个镜头固定从第 0 帧开始。
- **镜头时长不再手写**：本镜结束 = 下一镜开始；最后一镜到音频结束再加 15 帧（`TAIL`）。所以总帧数 = 音频帧数 + 15，永远对得上。
- 转场时长从**上一镜**里借（重叠的 Sequence），不额外加时长。前景只在退场转场的那几帧定格，不再有「提前 1 秒定格」（那样会和口播错位）。
- 切点选在**句子开头**，最好是段落开头（「第二笔账是……」）。一个镜头最少 1.2 秒，建议 4–9 秒；口播一个点讲很久就拆成两个镜头，几句很短的就合并。
- **动效锚点** `anchors`：整块内容用对应短句的字幕序号，或短句开头的原话。逐项列举时，每项绑各自词的起音。动画最多提前 2 帧起动，让台词刚开口就能看到入场。锚点必须落在本镜内，图片或文本框已设的锚点优先于固定延时。
- **版式**：`layout` 用 `matchEpisode()` 的结果，而且必须是 `layouts.ts` 里 `LayoutName` 已登记的名字。画面由 `Demo.tsx` 的 `ShotView` 渲染。未登记的名字会使 `npm run check` 和 `npm run check:constraints` 失败。`titleFloat` / `bareNumber` 只在匹配结果就是它们时使用。

| 版式 | 锚点键 |
|---|---|
| 通用标题 | `title` |
| titleFloat | `l1`、`l2`（两行标题）、`media`、`callout`、`chip0…` |
| bareNumber | `count`（数字开始滚动）、`formula`、`media` |
| splitVs / waitVs | `L`、`R`（左右数字）、`mediaL`、`mediaR`（左右图片） |
| ringFeature | `ring`（圆环）、`a`（数据卡）、`media` |
| timeline | `s0…`（节点）、`w0…w3`（图片窗）、`note`、`noteNext` |
| quoteStack / mediaRows | `r0…`（卡片）、`rsub0…`（卡片说明另起一句时）、`warn`（quoteStack）、`media`（mediaRows） |
| triadSoft | `c0…c2`、`note` |
| outroHost / outroAir | `line`、`p0…p2`、`note`、`account` |

未设锚点的元素用版式默认节奏。例如，`anchors: {r0: 7, rsub0: '举个例子'}` 让第一张卡随第 7 句开始入场，说明随「举个例子」开始出现。仅有 SRT 时，词内位置是估算；紧挨着说的多个词优先用逐词时间码核对。

时间轴需配图时，设置 `data.windows: [{label, src}, …]`（1–4 张，`src` 相对 `public/`），按顺序设置 `anchors.w0…`。图片自带短标签；下半区用图片窗替换原提示条。上一张保留，最新一张轻亮。交付前预览起音前后，检查卡片已起动、下一个词的图片尚未提前出现。

## 3. 视频素材长度
镜头时长由口播决定，可能比素材长。Demo 会按「素材时长 − trim」÷「镜长 + 转场」自动慢放，最慢 0.75 倍；比这还短 `npm run check` 会报错，换更长的素材或减小 trim。

## 4. 字幕设计（`src/style/subtitles.tsx`，参数在 `subtitle-tokens.ts`）
- 位置：底部 180px 字幕区（y ≥ 900）内，以画面中心 x=960 居中，离底 44px。
- 字：阿里健康体 Bold **40px**（允许 38–46），暖白 `#F4EEE4`，字距 1.5，柔和投影。
- 底：磨砂浅底胶囊——`rgba(18,17,16,0.38)` + 背景模糊 10px + 1px 淡金描边 + 圆角 16，内边距 10/28。不用黑色长条。需要去掉单镜字幕底框时设 `bareSubtitles: true`，保留文字和投影。
- 每行最多 18 个字（半角字符按 0.55 计），**优先单行**：句子太长就按词的时间拆成先后两条单行字幕，在原来的标点处断开、不拆数字；只有没有逐词时间时才用两行。
- 行尾标点全部去掉，句中标点换成空格，小数点和 % 保留。
- 动效：5 帧淡入 + 上浮 8px，4 帧淡出；两句间隔不到 600ms 就直接衔接，不闪烁。
- 卡拉 OK（有逐词时间时）：正在说的词变沙金色 `#F3D79E`；还没说到的字略暗（72%）。
- 开关：shots.ts 里 `SUBTITLE = {show, highlight}`；渲染时 `npm run render -- --no-subs` 或 `--no-highlight` 临时关闭。
- 音频：`<Audio>` 轨，导出 AAC 192k（`npm run render` 已不再静音）。

## 5. 检查（`npm run check` / `npm run stills`）
- 音频文件存在；总帧数 = 音频帧数 + 15；镜头起点严格递增、首尾相接无空隙；每镜至少 1.2 秒且至少含一句口播；每句字幕都落在成片内；所有 `at` 和锚点都能在本镜口播里找到。
- 字幕字号 38–46、每行 ≤18 字、最多 2 行；stills 抽 8 句在句中点出图 `out/stills/sub_XX.png`，检查字幕框在画面水平居中、y 900–1080 内且不溢出。
- 出片后 `ffprobe out/成片.mp4` 要看到 aac 音频流；在几句字幕的时间点截图，确认画面、字幕和口播是同一句。
