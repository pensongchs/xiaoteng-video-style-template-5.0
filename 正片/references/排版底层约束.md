# 排版底层约束（写在前面，正式出片少验证）

原则：所有约束都是**生成前或生成时用数字判断**（矩形运算、文字测量、背景亮度采样、动画函数取值），不靠逐帧截图看。正式交付只出 1 张「每镜中间帧」联系表，加 1 份自动报告。
示意图：`21_排版底层约束_安全区与检查.png`。坐标单位 px，画布 1920×1080，30fps。

## 1. 区域（硬边界）
| 区域 | 范围 | 规则 |
|---|---|---|
| 内容区 | x 96–1632，y 248–880 | 卡片、MG、AR 图形只能放在这里 |
| 栏目行 | x 96 起，y 56–92 | 只放 kicker，30px |
| 标题行 | x 96 起，y 100–200 | 标题 1 行，最多 2 行（hero 92px 时最多 2 行） |
| 字幕带 | y 900–1080，水平居中 | 只放字幕；单行 ≤ 18 字，最多 2 行，字号 38–46 |
| 抖音按钮区 | x > 1632 | 不放任何文字或卡片；小滕身体可以伸进来 ≤ 48px，脸和手势必须在 1632 以内 |
| 片尾小滕 | 底边贴画布底，高 760–900 | 脸部框不能和任何卡片、字幕相交 |

## 2. 网格与间距
- 组矩形只能用 `cols()` / `splitRows()` 生成，左右边落在栏线上（沿用 check-layout）。
- 独立组之间 ≥ 48px，组内元素之间 ≥ 24px；卡片内边距 ≥ 32px（胶囊 12/28），文字到卡边 ≥ 32px。
- 斜切、拱窗、六边形这类异形卡：按**内接安全矩形**排字（例：六边形取中间 60% 宽，拱窗取弧线以下部分，斜切面板让出斜边一侧 14% 宽），文字只能放在这个矩形里面。

## 3. 不重叠（矩形相交检查）
同一张卡内部也算：标题、说明、数字、标签的文字框不得与卡内图形、人偶、图标、刻度、户型构件或其它文字框相交。文字和图形之间的净距 ≥ 24px。检查读场景里的 `texts` 和 `marks`，用矩形间距，不看截图。
- 类别：文字框 T、卡片 C、字幕 S、小滕 H（含脸部框 Hf）、AR 图形 A。
- **禁止**：T∩T、T∩S、T∩Hf、C∩S、C∩Hf、任何元素压到抖音按钮区（小滕例外，见上表）。
- **允许的叠压（白名单）**：前景小签压住卡边，不超过小签面积的 20%，且不能盖住卡内文字框；小滕的手扶卡边，伸进卡片 ≤ 120px，同样不能盖字。**线条不在白名单里**，见 3b。
- 文字框按**字体实测**算（构建时用同一字体文件测量宽度，或用 DOM 在 1 帧里测），不截图。

## 3b. 线条不穿模（2026-11-13 老板反馈后新增）
磨砂卡是半透明的，线从卡片下面穿过时会透出来，看起来就是穿模。所以：
- 适用范围：连线、引线、流程线、AR 路线、尺寸线、光线、声波，以及所有 SVG `path`/`line`。
- **硬规则**：每条线按 2px 步长采样，任何采样点（加上线宽的一半）都不能落进任何卡片的**真实形状**里，包括 clip-path 多边形、圆角、六边形、拱形和斜切形。命中一点就判失败。
- 端点：线必须止于卡片外沿 0–6px，端点画一个圆点或箭头。起点也一样，不能从卡片内部起笔。
- 流程类版式（六边形步骤、弯道、时间轴）：连线只画在模块之间的缝隙里，缝隙 ≥ 32px。模块靠得太近、放不下线时，改用「下排卡片 + 竖直短引线」或者直接去掉连线，不准让线穿过模块。
- 曲线路径和卡片分区放：路径占上带，卡片占下带，两带之间 ≥ 40px（再加路径线宽的一半），每张卡片用竖直短引线接到它的节点上。
- 检查方法：对路径和形状多边形做几何相交运算，构建时就能算出来，不需要截图。
- 失败时依次：① 把线截短到卡边 → ② 改走缝隙 → ③ 换「下排卡片 + 竖直引线」布局 → ④ 去掉这条线。

## 4. 文字与字号
- 字号层级：kicker 30 / 标题 80（hero 92）/ 引语 60 / 卡标题 38–46 / **正文和说明 34（硬下限）** / **标签、胶囊、序号、单位、角标、图上房间面积 28（硬下限）** / 大数字 72–150。行高 ≥ 1.3。一帧最多 4 种字号。
- 说明性小字一律按正文算：卡里的副说明、步骤说明、批注、清单解释都 ≥ 34px，粗体（Health 85B）。不能为了塞进卡片把说明降到 26–32px（老板指出「小字太小看不清」）。28px 只给标签类元素用。
- 异形卡（六边形、拱窗、斜切）的说明按内接安全矩形限字：六边形每行 ≤ 6 字、最多 2 行；斜切面板每行 ≤ 10 字。超了就换版式，不缩字号。
- 字数上限：标题 ≤ 14 字，金色部分只有 1 处；卡标题 ≤ 8 字；正文每行 ≤ 16 字，最多 2 行；胶囊 ≤ 6 字；字幕 ≤ 18 字/行。
- 填充率：文字宽 ≤ 容器宽 × 0.75（沿用 RULE.fillMax）。
- 超出时的处理顺序：① 换同意图里容量更大的版式 → ② 拆成两镜 → ③ 只有卡标题可以降一级（46→40），正文和说明不降。**禁止**自动缩成小字。

## 5. 单帧元素上限
标题 1 个、卡片组 ≤ 3 个、卡内文字条目合计 ≤ 6 条、AR 覆盖层 ≤ 1 个、色调 ≤ 2 种、大数字 ≤ 2 个、胶囊 ≤ 4 个。超出按第 4 节的顺序处理。

## 6. 对比度（自动开关，不肉眼判断）
- 对每镜背景在入点、中点、出点各取 1 张 192×108 缩略帧（ffmpeg 直接算，不存图），计算 kicker、标题、每张卡片区域的平均亮度 L（0–1）和 90 分位亮度 P90。
- 标题和左侧文字：L > 0.45 或 P90 > 0.75 → 开「暖影 + 描边」（.tx2）；L > 0.65 → 再加薄磨砂提词条；L < 0.45 → 保留 5.0 原字影。
- 卡片：估算卡面颜色 = 卡后背景平均色经过 blur 和 brightness 1.12 处理，再叠上填充色（α .74/.64），算出深墨字和卡面的对比度。正文 ≥ 4.5:1，≥ 72px 的大数字 ≥ 3:1。不够时：背景 L < 0.3 → 开 .lift（填充 +0.10）；仍不够 → 填充 α 加到 0.88；再不够 → 换同色系更浅的色调。不允许改成深底白字卡。
- 背景本身：blur 必须为 0（沿用检查），压暗量 ≤ 0.2，避免画面太暗。

## 7. 动效（函数取值检查，不录屏）
- 所有入场曲线单调递增，到位帧精确等于 1：16 / 18 / 20 / 12 帧（卡 / 异形卡 / 软入 / 胶囊），最长不超过 24 帧。
- 到位后，除了背景推近（每镜 ≤ 6%）和小滕待机（上下 ≤ 6px），其他 transform 都不能再变。检查方法：对每个元素的动画函数取「到位帧 → 镜尾」的值，和最终值比较，必须完全相同。
- 错峰间隔 ≥ 4 帧；卡片在口播锚点词上开始入场；到位后至少停 12 帧镜头才结束。
- 吊牌摆动、太阳走弧这类「带动作」入场：振幅单调衰减，结束值精确等于静止值，没有二次回弹。

## 8. 节奏与音效（时间轴检查）
- MG 镜头 2–5 秒；每 2–3 个 MG 镜头之间至少插 1 段 1.5–2.5 秒、不带卡片的 B-roll；单镜 ≥ 1.2 秒（沿用检查）。
- 音效只有 4 类：whoosh、玻璃轻叩、tick、软低音点。相邻两个音效间隔 ≥ 15 帧，tick 每期 ≤ 10 次，音量比人声低 18–24 dB，B-roll 段不加音效。

## 8b. 户型图画法（2026-11-13 老板反馈后新增）
户型类画面必须像国内常见的住宅户型图，不能画成「一箱矩形房间」的卡通拼图。生成时逐项检查，缺一项就判失败：
1. **墙有厚度**：外墙 ≈ 240mm，内墙 ≈ 120mm，按比例画成双线墙（两条边线中间浅色或斜线填充）。不能用单线或圆角框代替墙。
2. **门**：门洞断开墙体，画门扇线和 90° 开门弧（虚线）。卧室和卫生间门宽 0.8–0.9m，入户门 0.9–1.0m。客厅和阳台之间画推拉门。
3. **窗**：外墙上的窗画成三线窗（两条墙边线加中间一条线），浅色填充。卧室、客厅、厨房必须有外窗；卫生间允许暗卫，但要标注。
4. **功能齐全**：入户门、玄关（可放鞋柜）、客厅、餐厅、厨房、卫生间、卧室，以及常见的南向阳台。厨房和卫生间靠外墙或管井，卧室不放在入户正对面。
5. **比例真实**：按 1m = 固定像素等比例画。参考尺寸：主卧 ≥ 3.3m×3.6m，次卧 ≥ 2.7m×3.0m，客厅开间 ≥ 3.6m，卫生间 ≥ 1.6m×2.0m，阳台进深 1.2–1.8m。各房间面积相加应接近标注的套内面积（误差 ≤ 5%）。
6. **标注**：房间名 ≥ 30px，面积 ≥ 28px（单位 ㎡）。至少一条总尺寸线（单位 mm）和一个指北针。家具只用浅色细线，示意床、沙发、餐桌、洁具和厨柜即可。
7. **动线**：只能经过门洞和开敞口，不能穿墙；每段路径都要和墙体矩形做相交检查。动线是虚线，起点画入户箭头，终点画圆点。房间名和动线要错开 ≥ 12px。
8. **数据来源**：优先用当期真实户型的矢量描图。没有就用模板里的标准户型库（两室、三室、四室各 2 套），并标「示例」。不能凭空拼房间。

## 9. 失败处理与交付验证
- 生成器按「意图候选 → 约束求解 → 降级阶梯」自动跑，最多降级 2 次：
  1. 换同意图的下一个候选版式；
  2. 拆镜，或换容量更大的版式；
  3. 还不行 → 标记「需人工」。**只有这些镜头**出 1 张中间帧给人看。
- 交付时只看：`check:layout` 报告（以上 1–8 条全部 ✓）、1 张每镜中间帧联系表、成片 1 遍。不再逐镜截多帧。
