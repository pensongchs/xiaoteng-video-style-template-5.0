# 5.0 质感卡片风格 · Remotion 设计规范（4.5 版）

> 写给 Remotion / 写 Remotion 的人与 AI。新视频只写 `shots.ts` 数据，**不写坐标**。  
> 代码：`src/style/`（grid / tokens / layouts / components / archetypes / types），示例：`src/demo/`。

## 0. 核心原则
1. **背景铺满、元素浮上**：每镜都有相关实景背景（视频或图，压暗 0.4–0.6，可模糊），上面叠 MG。
2. **不全是大玻璃卡**：一屏最多 1–2 张「重」玻璃卡；优先用裸数字、时间轴、细行、引用号、进度环、软提示条、浮动标签、下划线等轻量元素。大小元素穿插，禁止十镜同构。
3. **严格网格**：左右边必须落在 12 栏栏线上，内容块间距 ≥24px，**禁止重叠**。页眉三行（栏目/标题/示例标注）之间允许 8px。
4. **不要装饰框**：禁止金色 L 形角标、聚焦框、外发光框。质感靠玻璃底、细描边、内高光、投影。
5. **一屏一件事**：正在讲的那项最大、最亮；金色面积全屏 ≤8%。
6. **安全区**：底部 180px 字幕禁区；右侧约 15% 留给抖音按钮。
7. **素材规则（学员版）**：
   - **禁止**依赖本地剪映 / Mac 私有素材。
   - 城市航拍等视频放在 `public/media/stock/`，来源写进 `stock/SOURCES.md`（Mixkit / Coverr 等可商用免费授权）。
   - 关键概念用 `GenerateImage` 生成，放 `public/media/gen/`。
   - **一片一用**：同一文件在一条片子里只能出现一次（背景与框内都算）。
8. **数字标示例**：示例数据必须显示 `ExampleMark`（片尾除外）。

## 6. 动画时序（5.0 运镜版）
- **运动语言**：Q 弹入场（Remotion spring：过冲→回落）+ 镜间运镜（推/拉/漂/起）+ 镜头内视差推近。方向跟内容走（对比横移、流程轻横移、标题推近、片尾稳住），不乱跳。
- 入场约 24 帧弹簧；位移 ≤48px；缩放可过冲到约 1.08 再回 1；可 blur/fade。`SPRING.enter/soft/snappy/cam` 见 tokens.ts。
- 顺序：页眉 → 主元素 → stagger 5 帧依次弹簧出现。
- 焦点接力（timeline / IconRow）：约第 24 帧到 dur−60，当前项最亮。
- 结论条：dur−56 左右弹簧弹出。
- 镜头起止由字幕时间码决定（§10）；前景只在退场转场的几帧定格；镜间用 16–18 帧运镜转场（见 §9）。成片带口播音频和烧录字幕。
- 每镜 5–7 秒；整片约 60 秒、约 10 镜；**相邻镜版式不得相同**。

## 9. 终版（v3）新增硬规则
### 9.1 城市中立
- 文案、组件、样片中不得出现任何城市名；城市只能写在镜头的可选字段 `city`（如 `city: '长沙'`）。设了 city 时 kicker 自动加前缀，不设则不显示。
- check-layout 会用正则扫描 `city` 字段以外的城市名。
- 背景素材可能拍到真实城市的天际线，学员可以按自己的城市替换素材。

### 9.2 字号下限（tokens.ts `MIN_FONT`）
- 正文 / 说明文字（`data-role="body"`）≥ 34px；标签、chip、kicker ≥ 26px。
- 当前令牌：kicker 30、title 80、heroTitle 92、number 150、quote 60、rowTitle 40、body 34、label 28、chip 28、ringValue 52。

### 9.3 留白与填充率
- 带 `data-fit` 的容器（chip、pill、callout）里，文字宽度不超过容器宽度的 75%（`RULE.fillMax`）。
- 多行文字行高 ≥ 1.3（`RULE.lineHeight`）。
- 不允许溢出。所有文字必须落在 layoutRects 给出的版式区内（容差 ±6px）。装饰性字形加 `data-deco` 可以跳过检查。

### 9.4 组间距
- 独立的 MG 组之间至少相隔 48px（`MG_GAP`）：横向隔一个空栏，纵向用 `splitRows` 留 48px。只有连接件（`conn*`）可以放宽到 24px。
- 内容区从 contentTop 248 开始，高度 632。

### 9.5 片尾（outroHost）
- 默认版式 `outroHost`（`outroAir` 为同一实现的别名）。小滕卡通（`media/character/xiaoteng_outro.png`，挥手+竖拇指）默认出镜：占左侧约 1/3 宽、底边贴画面底并渐隐，脚下暖色地面光晕；从左下柔和滑入 → 轻微呼吸浮动 + 小幅摆动模拟挥手。`character:false` 关闭，文字居中。
- 右侧 5–11 栏按片尾文案分层：眉标 → 主标题（核心观点，可一处金色）→ 金线 → 要点玻璃条 `points`（≤3 条，编号 01/02/03）→ 收尾句 `note` → 小字署名 `account`（如「极限小滕 · 房产科普」）。
- 数据：`OutroData = {eyebrow?, line, points?, note?, account?, character?}`。屏幕文字只来自当期片尾文案。
- **禁止引导语**：模板不加、也会自动过滤含「点赞/关注/收藏/转发/三连/评论区/订阅」的要点/收尾句；不做按钮式 CTA。

### 9.6 转场（运镜衔接，替代硬切）
| 序号 | 类型（旧名兼容） | 帧数 | 做法 |
|---|---|---|---|
| 1 | softPush（原 pushBlur） | 18 | 相机侧向推入，弹簧落地；旧镜反方向滑出并虚化 |
| 2 | softZoom（原 crossfade） | 16 | 推近落地 + 柔光扫；旧镜放大淡出 |
| 3 | driftDissolve（原 maskWipe） | 16 | 同向漂入叠化，空间连续 |
| 4 | liftReveal（原 lightSweep） | 18 | 自下上浮揭示，模糊变清晰 |
- 上表四种转场按顺序轮换（transitions.tsx）。旧 kind 名仍可映射到新实现。重叠 Sequence：旧镜定格延长 T 帧，总时长不变。镜头内 Backdrop 另有缓慢推近+方向漂移（CamCtx），前景同向更快一点做视差。

### 9.7 亮度
- （5.0 调整，背景比 4.5 更亮）背景遮罩 = max(0.13, dark − 0.26)，滤镜为 `brightness(1.2) saturate(1.06)`；渐变只留左上标题区（径向 0.42）和底部字幕区（0.36），中部通透；文字可读性靠 `.txs` 柔和投影（0 2px 14px rgba(0,0,0,.55)），金字用 drop-shadow。4.5 原值为 max(0.22, dark−0.16) / brightness(1.1) / 上下渐变。COLOR.sub 的不透明度为 0.78。
- 按时段设 `bg.dark`：白天航拍 0.38–0.45（5.0 实际压暗 0.13–0.19），黄昏或阴天 0.45–0.52，夜景 0.52–0.60，静图背景 0.45–0.55 并加 blur 6–8。白天天空过曝时加 blur 2–4，或者换 trim。详见 `素材与生图规则.md` 的 C 部分。

### 9.8 检查命令
- `npm run check`：静态检查，包括贴栏线、组距、素材不复用、城市名、字号令牌。
- `npm run stills`：静态检查加 DOM 检查（用 @remotion/renderer 打开 onBrowserLog，读取每镜定格帧的 `CHECK|id|[...]`），同时输出 `out/stills/*.png` 和 `out/联系表.png`。只有全部 ✓ 才能出片。

### 9.9 防「顿一下」（4.5 修复）
- （4.5 音画同步版起，定格只发生在退场转场期间）定格**只冻结前景**（文字和 MG）。背景视频和媒体框里的视频继续播放：`LiveFrameCtx` 记录真实帧，`LiveVideo` 用 `<Freeze frame={真实帧}>` 跳出外层的定格。
- 静态图背景按真实帧缓慢推近（`scale 1.02 → +0.0003/帧`），所以静图镜头也不会停住。
- 每个 Sequence 都设 `premountFor={30}`，提前 1 秒挂载下一镜，Studio 预览时不会因为加载而卡一下。
- 视频素材时长必须 ≥ trim + 镜长 + 0.5s（转场时旧镜头还要多播 T 帧）。素材太短时，末尾会停在最后一帧，`npm run check` 会报错。
- 验收方法：对成片逐帧求亮度差（ffmpeg `signalstats` 的 YDIF），**不能出现连续 ≥2 帧差值为 0** 的情况。24/25fps 素材每 4–6 帧会有 1 帧重复，这是帧率换算造成的，属于正常现象。


## 10. 音画同步与字幕（4.5 音画同步版）
完整说明见 `references/音画同步与字幕.md`。
### 10.1 同步规则
- 输入：`episodes/<期名>/` 下的音频 + SRT 和/或 Caption JSON；`npm run episode` 生成 `src/demo/episode.json`。
- `F(ms) = ceil(ms × 30 / 1000)`。镜头 `at` 绑定到句子；本镜时长 = 下一镜起点 − 本镜起点；最后一镜 = 音频帧数 + 15 − 起点。总帧数 = 音频帧数 + 15。
- 转场从上一镜借帧，不改变总时长。不再有固定的提前定格。
- `anchors`：关键元素在说到对应词前 6 帧开始入场，说到时到位；焦点类版式（timeline / quoteStack / mediaRows）随口播逐项移动。
- 素材比镜头短时自动慢放（≥0.75×）。
### 10.2 字幕设计
| 项 | 值 |
|---|---|
| 区域 | 底部 180px（y 900–1080），以内容区中心 x=864 居中，离底 44px |
| 字体 | 阿里健康体 Bold 42px（允许 38–46），字距 1.5，行高 1.32 |
| 颜色 | 暖白 `#F4EEE4`，投影 `0 2px 10px rgba(0,0,0,.45)` |
| 底 | 磨砂胶囊 `rgba(18,17,16,.38)` + blur 10 + 1px `rgba(243,215,158,.14)` 描边，圆角 16，内边距 10/28 |
| 行 | 每行 ≤18 字（半角 0.55），优先单行，长句按词时间拆成先后两条；只在无逐词时间时用 2 行 |
| 标点 | 行尾去掉，句中换成空格，保留小数点和 % |
| 动效 | 淡入 5 帧 + 上浮 8px；淡出 4 帧；间隔 <600ms 直接衔接 |
| 高亮 | 当前词沙金 `#F3D79E` + 3px 下划线扫过；未读到的字 72% 透明度；可关 |
### 10.3 检查
音频存在、总帧数匹配、镜头无空隙且递增、每镜 ≥1.2s 且含口播、每句字幕都在成片内、锚点可解析、字幕字号和行宽合规；stills 抽 8 句检查字幕框位于字幕区。


## 玻璃材质（5.0 默认 · 苹果磨砂玻璃）
- 统一用 `glassMat(mode, tint?, edge?)`（components.tsx）+ `GLASS` token（tokens.ts）；不要再手写低透明 rgba。
- 参数：`backdrop-filter: blur(28px) saturate(170%) brightness(0.92)`；深色底 dark（默认）填充 rgba(34,36,42,.62)→rgba(18,19,24,.70)；亮底 light 填充 rgba(252,250,246,.78)→.72。
- 1px 内白发丝边（.20）+ 顶部 inset 高光（.22）+ 柔阴影 0 14px 36px rgba(0,0,0,.32)。着色玻璃（gold/coral/green/高亮行）= 在底色上叠 tint，不做纯色块。
- 已默认套用：GlassCard dark/ghost、Chip glass/coral/green、IconRow（新增 glass 属性，默认 true；glass={false} 回旧细线行）、Timeline 步骤卡、StatPill、SoftCallout、titleFloat 要点行。
- 文字：卡内正文用 COLOR.warm/sub；小字芯片加 GLASS.textShadow；行号不低于 .62 不透明度。
- 片头玻璃卡在深空底上已可读，保持原样（GlassLight 彩光不变）。

## 玻璃材质 v5 修订（浅玻璃 · 防闪 · 液态玻璃 · 随口播节拍）

### 浅玻璃（覆盖上一节的 blur/brightness 参数）
- 不再使用 `backdrop-filter`（GLASS.blur = 'none'）。原因见下「防闪」。
- 暗色玻璃底：`linear-gradient(165deg, rgba(62,64,72,0.56), rgba(38,40,48,0.64))`（旧：34,36,42 @.62 → 18,19,24 @.70 + brightness .92，偏深）。
- 叠加固定镜面高光 `GLASS.sheen`（左上 16% 白 → 透明），保留 1px 发丝边、顶部内高光、投影与文字阴影，保证可读。
- ghost 底：rgba(50,52,60,.40)→rgba(30,32,40,.48)。字幕胶囊、柱状图同样去掉 backdrop-filter。

### 防闪（根因与规则）
- 根因 1：`backdrop-filter` 的元素只要祖先有 opacity<1 或 filter（入场 enterStyle、转场 blur/淡入、dim），Chrome 会把该祖先当作 backdrop root，玻璃只采样到组内（≈透明）；动画结束 opacity 回到 1 后又采样整幅画面（≈磨砂不透明）→ 一会儿透明一会儿不透明。
- 根因 2：高亮态是布尔切换，金色底、金色 chip、边框在 1 帧内跳变。
- 规则：玻璃一律用确定性半透明填充（不依赖 backdrop）；高亮 `hi` 是 0→1 连续弹簧量（激活弹起、被下一项接管时平滑退回），用叠加层 opacity 与 interpolateColors 过渡；Chip 支持 `hi` 交叉淡入金色。

### 随口播节拍（mediaRows / quoteStack / timeline 默认）
- 行卡在锚点词说出时入场（`r0/r1/r2`、`s0/s1/s2`，提前 6 帧）；没有锚点时每行间隔 40 帧，不再一次全出。
- quoteStack：引文逐行（`q0/q1`）、副句按逗号分段（`sub0/sub1`）出现；第一张卡进来后引文退后变暗（焦点交接），`warn` 出现时整体回亮。
- 当前项高亮、前项变暗（opacity −30%、缩 1.5%）；镜头每一拍向焦点轻推（≈3–6px、+0.3% 推近）。
- 目标：长镜头每 1.5–2.5s 至少有一处有意义的变化。

### 液态玻璃（Q 弹）
- `useLiquid(start)`：弹簧速度→沿运动方向拉伸（≤6%），过冲→落地压扁（≤3.5%）。
- 邻居让位 `bump()`：新卡落地后约 6 帧，相邻卡被轻推开 9px/距离，再弹回。
- `Sheen`：入场与焦点切换时一道斜向镜面高光扫过玻璃（22 帧，强度 .22–.28）。
- 高亮卡放大 2%，与邻居的间距随之收放（合并/分离感）。克制，不做卡通形变。

### 片头起步（防前 0.5s 卡顿）
- 根因：片头 0–560ms（slam 之前）卡片 opacity=0，画面只有 ≈10px 的环境光漂移，逐帧差≈0 → 看起来冻住；另外拼接后视频首帧 PTS=21ms（AAC 预滚），混流 `-r 30` 在 0s 补了一帧重复帧，并造成 21ms 音画偏移。
- 规则：第 0 帧起卡片已在空中加速下落（预运动），整体镜头 1.06→1 推近；字体用 delayRender 等待；混流时视频加 `-vf setpts=PTS-STARTPTS`。

- 片头起步（v6 修正）：卡片用单一连续曲线下落——第 0 帧起 y=-420→0、scale 0.74→1，Easing.bezier(.42,0,.2,1)，在 slam+8 帧落地；落地后仅一次 ≤3px 过阻尼沉降（spring damping 26），禁止再叠加二次 drop / 欠阻尼 spring 驱动 scale。

- 图卡跟随口播（v7 默认）：media/split 版式的图卡与箭头不在镜头开头出现。先出左侧文字，再按 anchors.media（无则在标题之后）入场；splitVs/waitVs 依次为 左文字→左图→箭头(R 锚点前约 0.5s)→右图(R 锚点)。
