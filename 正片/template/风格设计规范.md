# 5.0 新定版（玻璃v6 + 房产MG）· Remotion 风格规范

已定：2026-11-06（Asia/Shanghai）。本规范只更新本目录5.0正片模板；独立4.5、片头模板/母工程和既有定版成片不修改。旧玻璃v5/液态弹簧/待审轮换条款废止，以下为新一期默认。

## 0. 原则与网格
- 深色电影实拍背景保持清晰（blur=0）、卡片用暖雾磨砂、暖白主字加暖褐描边、一处金色主强调；一帧最多两种低饱和色调。
- 不全屏堆大卡；先选信息结构，再挑版式；每镜1个主信息+2–3辅助信息。
- 1920×1080@30fps；12栏，left96/right1632，栏宽106/沟24/步长130；栏目y56/h36，标题y100/h100，内容y248–880。
- 所有矩形来自 `layouts.ts` 的 rect/splitRows；独立组距≥48px（左右空一栏），连接件conn*≥24px；页眉间距允许8px。严禁截字、重叠、角标装饰框。
- 底部y900–1080给字幕；右侧288px留平台按钮。
- 字体 PuHui/Health/ArialB；TYPE：kicker30/title80/heroTitle92/number150/quote60/rowTitle40/body34/label28/chip28/ringValue52。
- 正文和说明≥34px，标签/胶囊/序号/面积≥28px，房间名≥30px，多行行高≥1.3，文字填充≤75%；当前项靠颜色/亮度强调，不靠卡片弹跳或变形。

## 共享材质：暖雾磨砂（GLASS_V6 / v6.1）
- 唯一来源仍是 `tokens.ts` 的 `GLASS_V6`；`FROST = GLASS_V6`。`glassMat()`、`mgEstate.frost`、`mgCards.LG` 都走它。背景视频 blur 必须为 0。
- 卡内 `backdrop-filter: blur(26px) saturate(1.3) brightness(1.12)`，模糊不出卡面。填充 `rgba(250,243,231,.74) → rgba(236,224,204,.64)`，香槟/暖纸，不是灰底或深色底。暗底可 `lift` 填充 +0.10。
- 上沿 1.5px 高光，内底暖色反光，外圈 36px 暖金柔光，1.6px 微弱青/雾紫边缘，不发粉、不彩虹。极细颗粒只在卡内。
- 卡内文字用同色系深墨（香槟 `#2A1E12`，墨蓝 `#10203A`，茶绿 `#10281C`）。亮背景上的标题用 `#FFF8EC` + 4px 暖褐描边和暖色光晕；亮度 L>0.65 再加右端渐隐的薄磨砂条，不加黑条。
- 色调五种：香槟、暖纸、墨蓝、柔茶绿、淡陶土。一帧最多两种。
- 入场：主卡 16 / 异形卡 18（quint）/ 柔和 20 / 胶囊 12 帧，单调、到位精确为 1，之后除背景推近（每镜 ≤6%）和小滕微晃（≤6px）外不再动。无回弹、无过冲。
- `Sheen` 仍返回 null，`bump` 仍返回 0。片尾可选用 `interact:'hold'`（托房投出小结）或 `interact:'talk'`（对话气泡+便签），禁止点赞/关注类 CTA。

## 5.0 新定版（玻璃v6 + 房产MG）· 默认版式与轮换
状态：**已定**，2026-11-06（Asia/Shanghai）。本节替代此前“待审/旧6套强制/到位后持续呼吸”等条款。

默认 **26种逻辑版式**（`outroAir` 仅为 `outroHost` 别名，不重复计数）：
- 原核心10：`titleFloat / bareNumber / splitVs / timeline / mediaRows / quoteStack / ringFeature / waitVs / triadSoft / outroHost`。
- 数据7：`lineReveal / barGlow / rankBars / waffle / balance / yearRing / formulaCalc`。
- 房产已定9：`floorLadder / paymentSplit / amenityOrbit / pitfallBoard / priceStep / decisionFork / districtTags / loanDial / layerReveal`。
- 旧6套只存档：`keywordCascade / checklistFill / vsScore / tipStack / numberedReveal / kpiGrid`。材质已同步v6，但不自动推荐、不进入默认gallery。
- `unitCompare` 仅保留实现存档；不在 LayoutName、默认推荐、预览或轮换计数中。

执行条款：
1. 标准8–12镜一期至少7种版式，其中至少2种不同的已定房产MG；短片少于7镜时不硬凑7种，逐镜不重复，优先安排1种语义匹配的房产MG。禁止为凑数量造数据。
2. 同一版式每期最多2次（片尾仅1次）；相邻镜不得同版式，重复时中间至少隔2镜；别名合并计数。切换数字、流程、清单、图文、对比等信息结构，不只换标题。
3. 真实数字/比例/金额至少1镜用数据图表、bareNumber/ringFeature，或匹配的 paymentSplit/priceStep/loanDial。7种数据图表合计每期≤3镜，同一种≤1镜，不相邻连用；数字先核算，示例显式标注，不能把示例用于实际楼盘判断。
4. 清单/避坑优先 pitfallBoard、layerReveal，配合 quoteStack/mediaRows；楼层用 floorLadder，预算用 paymentSplit/priceStep，配套/区域用 amenityOrbit/districtTags；评分、热度必须有来源和口径，没数据就不造分。
5. 对比/决策轮换 decisionFork、splitVs、waitVs，真实总账可用 balance；禁止默认使用 unitCompare 或旧 vsScore。
6. 背景优先清晰视频，静图背景占比≤1/3；不整屏模糊，bg.blur=0，靠冷灰玻璃和字影保证可读。
7. 卡片按口播锚点单调入场，16/20/12帧后精确停稳；禁止过冲、落地二次弹、邻居让位、整体呼吸/焦点缩放、僵硬扫光条。高亮只改变轻色光/文字亮度；数据绘制、进度填充、背景自然运镜与小滕人物摆手可保留，不让卡片整体晃动。

唯一登记：`src/style/layouts.ts` 的 DEFAULT_LAYOUTS（10+7+9）；默认活目录 `src/gallery/shots-mg-gallery.ts` / `MgGallery`，每个默认版式一镜。房产子集 `shots-mg-re10.ts` / `MgGalleryRe10` 固定9镜、40.5秒；“re10”仅兼容旧文件名，不代表10套。
检查：`npm run check:freeze` 验证材质、动效范围、默认/存档边界和gallery覆盖；正式出片还须 `npm run check`、stills/音画核验。新增版式必须先登记样镜并审核，不能直接加进默认清单。

## 口播节奏与转场
- 镜头起点按字幕 `at:{cue/text/ms}`；不用手写sec。`F(ms)=ceil(ms*30/1000)`，总帧数=音频帧+15，无空隙。
- 图卡、文本框、提示条按对应短句起点入场；逐项图片窗按各自关键词起音入场。锚点最多提前2帧起动；明确设置的图片或条目锚点优先于固定延时。用实际口播预览微调，保留字幕时间码。
- MOTION：enter16/stagger5/chip12/count32/focus12/freeze30/maxShift48（30fps）。卡片只做单调进入，到位停；滚数/画线按语义推进。
- 正片转场保留 softPush18 → softZoom16 → driftDissolve16 → liftReveal18；旧kind名兼容。用有限单调缓动，在dur末帧精确到位；去掉softZoom移动扫光，禁止spring超调。房产子gallery继续独立10帧柔叠化。
- 前景只在退场转场延长帧冻结；LiveFrameCtx/LiveVideo保证背景与媒体视频不停，每个Sequence premountFor30；不为“有动效”而让已到位卡片继续晃。

## 背景、素材与亮度
- 视频≥1920×1080、中国城市航拍、优先白天与当期城市，可商用无水印；一片一用，登记SOURCES并跑stock:verify。概念图无文字/logo/水印，≤300KB。
- `bg.blur=0`，不糊整幅背景。brightness1.2/saturate1.06；实际压暗max(.13,dark−.26)，只留标题/字幕区渐变；白天dark .38–.45，黄昏.45–.52，夜景.52–.60。曝光或可读性差先换trim/素材或调压暗，不能回白卡。
- 素材长度≥trim+镜长+转场余量，太短最多慢放至.75×，再短换素材。保留视频播放和背景自然缓慢运镜。
- 不写死城市/人名；城市只在可选city字段；样例均显式标示例，正式金额/月供/税费先核算。

## 字幕、片尾与工作流
- 配音→逐字时间码→只校对文字不改时间→镜头表/anchors→check→stills→render→核对音画。详见音画同步与字幕.md。
- Health Bold40px（38–46）、暖白+当前词沙金，底部默认磨砂胶囊，可按镜头仅保留带投影的字幕；自然断句、行尾去标点，每行≤18字，优先单行、最多2行。当前实现以画面中心x960居中；无下划线。
- 片尾outroHost默认左侧小滕+右侧文案；outroAir同一别名。只用当期文案，points≤3；无点赞/关注/收藏/转发类CTA。人物微呼吸摆手保留，玻璃要点条停稳。
- 片头（EpisodeOpening/GlassLight）遵从片头原规范，未改实现；既有选楼层口诀等成片只作历史参考，不能用旧片倒推覆盖本次玻璃v6。
- 一体build/concat/setpts混流流程不变；本轮不重制旧片、不推GitHub、不Copy Mac、不代发消息。
